# Rokid Settings Hub

Independent Android app project for Rokid AI Glasses.

## Goal

Build a glasses-first `Settings Hub` app with a system-like UI.

## v1 Scope

- `Bluetooth` is the only fully implemented section
- `Wi-Fi`, `Battery`, and `Device Info` are placeholder or read-only sections
- `Main Phone` can be assigned by the user
- `Main Phone` cannot be forgotten in v1

## Out of Scope for v1

- CXR-S integration
- Camera
- Microphone
- Background services
- Heavy graphics or long-running workloads
- Full Android Settings feature parity
